🔗 Tally Sync Test

Reads Stock Summary from Tally ERP 9 on this machine

How this works:
Browser → your Render server → Tally on this PC.
Your server already has a /tally/invoices proxy endpoint — we use that.
Tally port stays 9000 (ODBC port also accepts XML on the same port in ERP9).
⚠ This needs the accountant to be logged in
The /tally/invoices route requires auth. Open accountant.html first and log in, then come back and click Test — the token is shared in the same browser session.
⚠ Only works when served over HTTP, not opened as a file.
Run this command in the same folder as this HTML file:
npx serve .
Then open: http://localhost:3000/tally-test.html

If npx isn't available: npm install -g serve first.
