📖 How to use
  1. Enable engines — Tap chips above to toggle scanners on/off. Start with Hybrid + Quagga2.
  2. Start Camera — Tap ▶ Start, grant permission.
  3. Scan — Point camera at any barcode (Code128, EAN, QR). Hold 15-25cm away.
  4. Winner — First engine to detect fills the target. Log shows which one won and how fast.
  5. Rescan — Tap ⟳ without stopping camera.
